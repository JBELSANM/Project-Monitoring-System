# Project Monitoring System

Static HTML Project Monitoring System for Inspector, Contractor, and Project Engineer workflows.

## Start

Open `Updated Login.html` in a browser, or open `index.html` to redirect to the login page.

## Demo Accounts

- Inspector: `INS1234` / `INS1234`
- Contractor: `CON1234` / `CON1234`
- Project Engineer: `PE1234` / `PE1234`

## Notes

Data is stored in the browser using `localStorage`. The current version includes a one-time reset for old saved project/form data.
